# Security

Fluid runs in the browser and copies its pieces into your code, so most problems are fixed by editing your copy. If you find something that could hurt people who use Fluid, such as a way for the CLI to write outside the folder you chose or a piece that runs code it should not, please report it privately.

## Reporting

Open a [private security advisory](https://github.com/willradoux/fluidui/security/advisories/new) on GitHub. Say what you found, how to reproduce it and what it affects. You will get an answer within a week.

Please do not open a public issue for security problems.

## Supported versions

Only the latest release of `@usefluid/motion` and `@usefluid/cli` gets fixes.
