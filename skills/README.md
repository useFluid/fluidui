# Fluid skills

Skills that teach your agent to build motion with your brand, in the Fluid style: outlines that flow on real springs, shapes that become your logo, pills that flow and words that come out of a blur.

| Skill | For |
|---|---|
| [fluid-brand](fluid-brand/SKILL.md) | Finds your logo, colours and font, converts the logo and writes the `--fluid-*` theme |
| [fluid-components](fluid-components/SKILL.md) | Picks the right piece and adapts it to your project |
| [fluid-metamorph](fluid-metamorph/SKILL.md) | Builds new pieces with the engine, following the rules that keep morphs clean |
| [fluid-splash](fluid-splash/SKILL.md) | Builds your product's opening from your logo |
| [fluid-characters](fluid-characters/SKILL.md) | Creates pets and bots with moods tied to your product |
| [fluid-video](fluid-video/SKILL.md) | Records any page or piece as video, frame by frame |
| [fluid-ai-video](fluid-ai-video/SKILL.md) | Puts your brand's motion over AI-made video, with prompts and compositing |

Start with `fluid-brand`: the others use what it sets up.

## Install

```bash
npx skills@latest add willradoux/fluidui
npx skills@latest add willradoux/fluidui --skill fluid-splash
```

Or copy a skill folder into `.claude/skills/` in your project.
